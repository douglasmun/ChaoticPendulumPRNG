- Last 150 bytes in hexadecimal

- Auto-scrolls as new values appear

**Distribution Heatmap (Right):**

## How to Use

### Basic Operation

1. **Open the Application**
   - Launch `index.html` in a modern browser
   - Wait for pendulums to initialize
   - Verify status shows "System Healthy"

2. **Observe the Chaos**
   - Watch the pendulums swing
   - See values being generated
   - Check heatmap for distribution

3. **Interact (Optional)**
   - Move mouse near pendulums to inject entropy
   - Adjust force slider to control interaction strength
   - Watch trail colors follow your mouse

4. **Export Results**
   - Click 📋 **Export** button
   - File downloads as `prng_output_[timestamp].txt`
   - Includes metadata and warnings

### Advanced Usage

#### Seeding for Repeatability

**Use Case:** Reproducible sequences for testing

```
1. Set Seed slider to specific value (e.g., 42)
2. Click Reset
3. Generate samples
4. Record sequence
5. Repeat with same seed → identical sequence
```

**Note:** This proves determinism - NOT suitable for security!

#### Speed Optimization

**For Faster Generation:**
1. Increase Speed slider to 10
2. Decrease Force slider (less mouse tracking)
3. Minimize browser window (reduces rendering)

**Warning:** Higher speeds use more CPU and may reduce FPS.

#### Maximizing Entropy

**Best Practices:**
1. Use different seed values
2. Move mouse erratically near pendulums
3. Let system stabilize before collecting
4. Verify entropy > 7.5 bits/byte

## Understanding the Output

### Exported File Format

```
# Chaotic Pendulum PRNG Output - Production Build v2.0
# Generated: 2025-11-15T10:30:45.123Z
# Samples: 1523
# Entropy: 7.9234 bits
# Seed: 50
# Force: 30
# Speed: 5
#
# ⚠️ WARNING: NOT FOR CRYPTOGRAPHIC USE
# This output is from a demonstration PRNG and should NOT be used
# for security-sensitive applications...
#
# Hex values (one per line):
A3
7F
2C
...
```

**Fields Explained:**
- **Generated:** UTC timestamp
- **Samples:** Number of bytes
- **Entropy:** Shannon entropy (higher = better)
- **Seed/Force/Speed:** Settings used
- **Values:** Hexadecimal bytes (00-FF)

### Interpreting Entropy

| Entropy | Quality | Interpretation |
|---------|---------|----------------|
| < 6.0 bits | Poor | Very biased, patterns visible |
| 6.0-7.0 bits | Fair | Some bias, acceptable for games |
| 7.0-7.8 bits | Good | Good randomness, low bias |
| 7.8-8.0 bits | Excellent | Near-ideal distribution |

**Note:** Even perfect entropy doesn't mean cryptographically secure!

### Interpreting Heatmap

**Uniform Distribution (Good):**
```
All cells similar color
No clustering
Gradual color transitions
```

**Poor Distribution (Bad):**
```
Some cells very bright ("hot spots")
Large dark areas
Obvious patterns or clusters
```

## Troubleshooting

### Common Issues

#### Problem: "Browser Not Supported" Error

**Cause:** Browser lacks Web Crypto API

**Solution:**
1. Update browser to latest version
2. Try Chrome, Firefox, or Edge
3. Disable browser extensions that block crypto APIs

#### Problem: Pendulums Not Moving

**Symptoms:**
- Static pendulums
- No values generated
- FPS shows 0

**Solutions:**
1. Click Reset button
2. Refresh page (F5)
3. Check browser console for errors
4. Verify JavaScript is enabled

#### Problem: Circuit Breaker Triggered

**Symptoms:**
- Status shows 🔴 "System Critical"
- Modal appears
- Generation stops

**Solutions:**
1. Wait for auto-recovery (2 seconds)
2. If recovery fails, click Reset
3. If persists, refresh page
4. Check Health Check for details

#### Problem: Low FPS / Laggy

**Causes:**
- High speed setting
- Many browser tabs open
- Weak CPU

**Solutions:**
1. Reduce Speed slider to 1-3
2. Close other tabs
3. Disable browser extensions
4. Use dedicated browser window

#### Problem: "Sample Limit Reached"

**Cause:** Generated 100,000 samples (safety limit)

**Solution:**
1. Click Reset to continue
2. Export existing data first if needed
3. This is normal - limit prevents runaway generation

#### Problem: Memory Usage High

**Symptoms:**
- Browser becomes slow
- Memory > 400 MB in status bar
- System sluggish

**Solutions:**
1. Click Reset (clears old data)
2. Refresh page
3. Close and reopen browser
4. This is normal after extended use

## Frequently Asked Questions

### Q: Is this cryptographically secure?

**A: NO. Absolutely not.** This is a demonstration PRNG. Never use for security.

### Q: Can I use this for passwords?

**A: NO.** Use your browser's built-in password generator or a password manager.

### Q: Why is the same seed giving the same output?

**A: This is by design.** The system is deterministic - same initial conditions produce identical sequences. This demonstrates how PRNG works but also why it's unsuitable for security.

### Q: The heatmap looks uneven. Is it broken?

**A: Probably not.** Some clustering is normal, especially with small sample sizes. Check entropy value - if > 7.5, it's likely fine. Run longer for more uniform distribution.

### Q: Can I increase the sample limit?

**A: Not recommended.** The 100,000 sample limit prevents browser crashes. For more samples, export periodically and reset.

### Q: Why does it use my mouse position?

**A: To inject additional entropy.** Mouse movement adds external randomness to the deterministic chaos. This makes sequences less predictable but doesn't make them cryptographically secure.

### Q: Can I run multiple instances?

**A: Yes**, but each uses CPU/memory. 2-3 instances OK, 10+ may cause lag.

### Q: Is the output truly random?

**A: No**, it's pseudo-random. The pendulum motion is chaotic (appears random) but follows deterministic physics. Given initial conditions, future states are theoretically predictable.

### Q: What's the difference between chaotic and random?

**A: Chaos is deterministic but unpredictable;randomness is non-deterministic.** Chaotic systems follow fixed rules but are sensitive to initial conditions. True randomness has no underlying deterministic pattern.

## Safety & Privacy

### What Data is Collected?

**None.** This application:
- ✅ Runs entirely in your browser
- ✅ No network connections
- ✅ No analytics or tracking
- ✅ No cookies
- ✅ Completely offline after load

### What Data is Stored?

**Only in browser memory:**
- Last 2,000 generated bytes
- Pendulum states
- UI settings

**Nothing persists** after closing the browser tab.

### Can Output Be Used to Track Me?

**Potentially, yes.** The output is browser/device-specific due to:
- JavaScript floating-point precision differences
- CPU timing variations
- Initial `Math.random()` seed (browser-dependent)

**Different browsers/devices produce different sequences from the same seed.**

**Recommendation:** Do not share exported files publicly if privacy is a concern.
